# PostgreSQL Sales Analysis

## Project Overview
This project demonstrates SQL-based data cleaning and exploratory sales analysis using PostgreSQL.

Tools Used
- PostgreSQL
- DBeaver

## Project Objectives
- Clean inconsistent data formats.
- Standardize text values and missing data.
- Analyze sales performance using SQL queries.
- Summarize key business insights.

## SQL Techniques
- WHERE and CASE WHEN
- GROUP BY and aggregate functions
- Common Table Expressions (CTEs)
- Window functions
- Data type conversion and data cleaning
